Sunday 22 November 2026 in one image: 32 stories, 12 pinned on a world map, built for make.fun's ["Sum up 22 November's world news in one image"](https://make.fun/bounty/news-image-20261122) bounty.

The page is a world briefing — "The World in One Day" — in deep ink navy with a warm amber accent, a deliberate break from the front-page pattern of the previous editions. A masthead band names the day; three feature cards lead with the COP31 second overtime day, Iran hitting Bahrain and tankers near Hormuz, and the overnight drone attack on the Kyiv region; a large world map with twelve numbered pins anchors the middle; twelve illustrated grid stories follow; then seventeen more stories in a numbered list, region counts (Europe 10, Asia 7, Africa 6, Middle East 5, Oceania 2, Americas 1, Global 1), a date check and attribution. Thirty-two stories in all, across seven regions. All pictures are flat-design illustrations drawn for this page; all headlines and decks are set in crisp vector type.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
